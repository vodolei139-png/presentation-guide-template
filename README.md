# Presentation Guide Template

Генератор шаблонов для презентаций в стиле «страницы из путеводителя»: 10 готовых слайдов в Markdown + рекомендации по стилю.

## Зачем это нужно

- Быстро собрать структуру презентации на 10 слайдов.
- Получить готовый стиль (цвета, шрифты, декор).
- Использовать шаблоны в Google Docs, PowerPoint, Notion.

## Как пользоваться

1. Откройте сайт на GitHub Pages: [ссылка появится после публикации].
2. Скачайте нужный шаблон (`.md`).
3. Вставьте в свой редактор и замените заглушки на свои данные.

## Структура

- `templates/` — шаблоны слайдов 01–10.
- `css/` — стили для сайта-витрины.
- `index.html` — главная страница.
