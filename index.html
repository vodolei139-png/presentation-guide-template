Путеводитель по слайдам

Готовые шаблоны на 10 слайдов в уютном ретро-тоне. Как страница из старого путеводителя.

Как это использовать

  1. Скачайте шаблон нужного слайда (в формате Markdown).
  2. Скопируйте текст в Google Docs / PowerPoint / Notion.
  3. Подставьте свои данные, добавьте фото.

Стиль и типографика

Палетка цветов, шрифты, рекомендации по оформлению — чтобы всё выглядело как страница из путеводителя.

  • Цвета: тёплый бежевый фон, тёмно-коричневый текст, акцентный терракотовый.
  • Шрифты: основной — с засечками (Serif), заголовки — немного «старинный» гротеск.
  • Декор: тонкие рамки, уголки, линии-разделители, имитация печати.

Проект: шаблоны для презентаций. Стиль: ретро-путеводитель.
